Periodo 2026-II

ARCHIVOS
- index.html: estructura principal
- css/styles.css: diseño responsive y estilos visuales
- js/app.js: filtros, buscador, publicaciones, comentarios, menú móvil y almacenamiento local

USAR EN VS CODE
1. Abre esta carpeta en Visual Studio Code.
2. Abre index.html con Live Server.
3. Para publicar, sube index.html junto con las carpetas css y js conservando esta estructura.

NOTA
Las publicaciones y comentarios agregados desde la interfaz se guardan en localStorage del navegador. Para compartir datos entre visitantes se debe conectar posteriormente a Firebase/Firestore.
